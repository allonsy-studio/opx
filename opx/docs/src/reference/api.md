The generated [API reference](../../api/) covers everything exported by `@allons-y/opx`. You need it if you're:

- **writing a plugin**, and need the `Detector` and `DetectorContext` types, or
- **building your own host**, such as an editor integration, on opx's detector model.

End users install [`@allons-y/opx-cli`](../../cli/) instead; it depends on the engine.
