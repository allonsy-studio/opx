write()

write(chunk): void;

Defined in: detector.ts:118

Sink for a detector's primary (report) output — e.g. an ESLint results report. Defaults to stdout, but the CLI may swap in a buffer so concurrent detectors' output can be flushed grouped instead of interleaved. Use this instead of writing to process.stdout directly.
