opx: the optionally opinionated front-end toolkit.

opx scans your repository, works out which languages and workflows you have, and runs the matching plugins from your own node_modules. Install only the opinions you want.

Get started CLI reference API reference
  • Free & open source · Apache-2.0
  • Node 24+
  • Currently in beta
yarn add --dev @allons-y/opx-cli
yarn opx init
yarn opx lint

A tiny core

The CLI knows nothing about ESLint or changesets. It discovers plugins in your dependencies and delegates to them.

Opt in per tool

Enable only the detectors you want with opx enable. Nothing is installed or configured behind your back.

Composable configs

Every lint package exports a plain flat-config array. Spread it into your own eslint.config.js and layer your rules on top.

Release without ceremony

A lightweight changesets flow: record a change, version, and publish with one command family.
